# 戦略研究ノート

gmo-coin の `docs/research.md` の方法論を移植。**結論だけでなく棄却も記録する。**

## 研究の規律 (変更禁止。精緻化は日付と理由を付けてのみ可)

1. **WFAを標準評価とする** (学習365日/検証90日、OOSを複利連結)。
   1回きりのイン/アウト分割で良く見えた結果は信用しない
2. **採択単位は「戦略×ペア」とし、クロスチェックは必須** (2026-08-20改定):
   - クロスチェックは「同一メカニズムが成立すべき別ペア」で行う。
     普遍的な値動き戦略 (Donchian、BB/RSI等) は従来どおり複数ペアで
     再現しなければデータマイニングとして棄却
   - メカニズムが構造的にペアを選ぶ戦略 (セッション構造等) は、
     メカニズムが成立すべきペア群でのクロスチェック + **不成立ペアへの
     経済的説明の記録**を要件とする。説明は事後の後付けでなく、
     メカニズム仮説から導出できるものに限る
   - 改定理由: 旧規則「USD_JPY+EUR_USD両方必須」は普遍戦略の過学習排除には
     正しく機能した (R2-B棄却) が、セッション構造戦略には誤設計だった。
     R3-AのUSD/JPY不成立は「東京が自国通貨時間」というメカニズムの帰結であり
     過学習の兆候ではない。これは今回だけの例外ではなく一般則の精緻化である
3. **採択基準は実行前に固定** (`src/examples/research.ts` の ACCEPTANCE)。
   グリッドサーチ結果を「仮説」として提示しない
4. **スプレッド感度**: +0.2/+0.5pips 上乗せで期待値が消える戦略は棄却
   (DukascopyはECN系でOANDAリテールより狭い可能性が高いため)
5. **全戦略不採択 → live見送りが正式なアウトカム**。緩和期間の締切を理由に
   限界的な戦略を通さない。エッジのない戦略で月50万USD回すコストは
   Gold喪失より確実に高い
6. no-go時の「データ収集のためだけに口座開設」は**緩和期間 (開設月〜翌月末) 限定**の
   選択肢 (OANDA JP確認済み: その後は月50万USDの実取引がないとAPIが停止するため、
   オーダーブック収集の長期継続は取引なしでは不可能)
7. **戦略の状態は3値: 採択 / 棄却 / 観察中の候補** (2026-08-21新設、研究者レビュー):
   「観察中の候補」はパラメータ凍結のまま採択も棄却もせず、practiceフォワードの
   判定ログのみで観察する状態。昇格/失格条件はフォワード開始前に事前固定し、
   条件を満たして初めて採択議論を再開する。ペア間クロスチェックの事後弁護や
   「通るペアが出るまで別ペアを試す」逆方向p-hackingの代わりに、
   マイニング不可能な未来のデータに判定させるための状態
8. **データ完全性ゲート** (2026-08-21新設): WFAランナーは月次欠損率が閾値(20%)を
   超えるデータでの実行を拒否する (`src/data/completeness.ts`)。人間がギャップ
   レポートを読む運用は破られることが実証されたため、「不完全データでの検証結果が
   存在し得ない」ことを構造で保証する

## 採択基準 (2026-08-19 固定)

- OOS連結シャープ ≥ 0.5
- コスト控除後期待値 ≥ 平均スプレッドコスト × 2
- OOS最大DD ≤ 25%
- +0.2/+0.5pips 上乗せ後もOOS期待値 > 0
- 上記を USD/JPY・EUR/USD の両方で満たすこと

   崩壊**。2021-2026のUSD/JPYは円安の一方向トレンドであり、EMA200方向フィルタ≈
   実質ロングオンリーがその追い風に乗っただけ、という説明と整合的。
   **gmo-coinのレジームスイッチ (BTC年率64%→ETHで崩壊→過学習棄却) と同型**であり、
   クロスチェック規律どおり棄却する
2. ADXフィルタ (R2-C) は両ペアで悪化。ADX計算の遅行性がブレイクの初動を

3. 東京限定逆張り (R2-D) はEUR/USDでは大幅改善 (-1.59p→-0.37p) したが正にならず。

4. 横断的な結論: **ドンチャン系はフィルタをどう掛けてもコスト×2の壁を超えない。
   ブレイクアウトの「初動を終値確認で追いかける」構造自体が、M15/H1のFXでは
   1トレード期待値の上限をスプレッド近傍に抑え込んでいる可能性が高い**

判断の要旨 (研究者レビューより):
